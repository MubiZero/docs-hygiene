# Документы <Название проекта> (Map of Content)

Что здесь живое. Правило: **текущее состояние — в [status.md](status.md)**, контракт API — в [api.md](api.md), деплой и инфраструктура — в [deploy.md](deploy.md). Остальное — тематические справочники и записи решений ([decisions/](decisions/)).

## Карта связей: Модуль кода ↔ Документ ↔ Решения

| Модуль / Папка кода | Главный документ | Связанные решения (ADR) | Что внутри |
|---|---|---|---|
| `cmd/api`, `internal/` | [api.md](api.md) | [0001](decisions/0001-example.md) | Контракт API, авторизация, коды ошибок |
| `apps/`, `pkg/webkit` | [status.md](status.md) | — | Что выкачено на прод, что в сторах, что открыто |
| `deploy/`, `docker-compose.yml` | [deploy.md](deploy.md) | — | Coolify, домены, переменные окружения, бэкапы |
| — | [decisions/README.md](decisions/README.md) | Все ADR | Решения «почему так» с областью действия и условием пересмотра |

## История (убрано из дерева)

Выполненные планы и старые аудиты убраны из рабочего дерева, чтобы не путать с живым состоянием. Смотреть через `git log --all -- docs/archive/`. Правду о том, что открыто сейчас, ищи в [status.md](status.md).
