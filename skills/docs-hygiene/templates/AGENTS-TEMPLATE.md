# <Название проекта> — Project Guide

> Короткая таблица маршрутизации для агентов и разработчиков (до 150 строк). Подробности — в `docs/README.md`.

## Архитектура и модули

```
<project>/
├── api/               Go API (обработчики, миграции, бизнес-логика)
├── app/               Flutter-приложение (рабочие инструменты / мобильный клиент)
└── docs/              Карта документов (docs/README.md) и решения (docs/decisions/)
```

## Команды (сборка, проверка, запуск)

- **Анализатор / вет:** `cd api && go vet ./...` · `cd app && flutter analyze`
- **Тесты пакета:** `cd api && go test ./internal/...` · `cd app && flutter test`
- **Локальный запуск:** `./scripts/dev.sh`

## Критичные инварианты (2–3 строки)

- Секреты только через `~/.claude/bin/secret get <имя>`, в код и чат не печатать.
- Все строки интерфейса — через каталог локализации, без хардкода.
